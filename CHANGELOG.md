# Changelog

All notable changes to this project are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-18

### Added

- `terminal` pictures take a `"width"`, so a narrow one can stand in for a phone; descriptions
  name a width that is no number or below 200.

## [0.1.0] - 2026-11-18

### Added

- `markdown-graphics banner`: banners in an app theme with the project's icon and a Claude theme
  with a matching footer; asks for everything when started without texts.
- `markdown-graphics icon`: section icons in 23 colors, with a glyph name or own SVG shapes.
- `markdown-graphics pictures`: button, grid, chips, terminal, flow, layers, slideshow and compare,
  each drawn light and dark from a JSON description.
- `markdown-graphics.toml` for the project's name, icon and folders.
